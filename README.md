# Zepto_Data_Analysis

## 📦 Zepto Data Analysis Project

## 📌 Overview
This project presents an **end-to-end data analysis** of a Zepto-like quick-commerce dataset using **Python and SQL**.  
The objective is to extract **business insights**, analyze **product and pricing patterns**, and demonstrate a **real-world data analytics workflow** suitable for **Data Analyst roles**.

---

## 📁 Repository Structure

```text
zepto-data-analysis/
├── zepto_python.ipynb
├── zepto_sql.sql
├── zepto_v2(in).csv
└── README.md

```

## Business Problem
Quick-commerce platforms operate with:
- High transaction volumes
- Tight delivery timelines
- Low profit margins

This analysis focuses on answering key business questions such as:
- Which products and categories contribute the most to revenue?
- How do pricing and discounts impact product performance?
- What data patterns can help optimize inventory and pricing decisions?
